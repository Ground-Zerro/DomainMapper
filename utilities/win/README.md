## convert

Скрипт `convert.bat` загрузит актуальную версию утилиты с GitHub во временную папку, при необходимости установит Python 3 и нужные библиотеки, запустит конвертер и удалит временные файлы.

**Требования:** Windows 10 или новее (PowerShell 5+), доступ в интернет.

**Использование:**
1. Скачайте файл [convert.bat](https://github.com/Ground-Zerro/DomainMapper/raw/refs/heads/main/utilities/win/convert.bat).

2. Создайте файл `ip.txt` в той же папке, где находится `convert.bat`, и добавьте в него IP-адреса или любой текст, содержащий IP-адреса. Если файла нет, скрипт предложит создать пустой.

3. Запустите `convert.bat` и ответьте на вопросы. Результат будет записан в `ip.txt` (для формата Keenetic BAT — в файлы `ip_p1.txt`, `ip_p2.txt` и т.д.).

Если Python был только что установлен, закройте окно и запустите `convert.bat` снова.

`setup.bat` — служебный скрипт установки Python и библиотек, который вызывает `convert.bat`. Запускать его отдельно не нужно.

## extract_apex_domains

**Требования:** установленный Python 3.10 или новее, скачанный (клонированный) репозиторий.

**Использование:**
1. Запустите `extract_apex_domains.bat` из папки `utilities\win` репозитория.

2. Результаты будут сохранены в папке `platforms_apex` в корне репозитория.
