# Вспомогательные утилиты
- [convert - конвертер маршрутов](#convert)
- [extract_apex_domains - извлечение доменов первого уровня](#extract_apex_domains)
- [subdomain - поиск субдоменов](#subdomain)
- [verified - проверка активности доменов](#verified)

Все утилиты требуют Python 3.10 или новее и запускаются из корневой папки репозитория.
Зависимости для всех утилит устанавливаются одной командой:

```bash
pip install -r utilities/requirements.txt
```

## convert

Обрабатывает готовый список IP-адресов: исключает адреса Cloudflare, объединяет адреса в подсети и сохраняет их в виде маршрутов. Использует те же форматы и режимы агрегации, что и Domain Mapper.

### Функции

- Извлечение IP-адресов из файла `ip.txt`. Файл может содержать любой текст: корректные IPv4-адреса находятся автоматически, некорректные (например, `999.1.1.1`) пропускаются.
- Исключение IP-адресов Cloudflare (опционально).
- Агрегация IP-адресов:
  - `/16` (255.255.0.0)
  - `/24` (255.255.255.0)
  - mix: подсеть `/24`, если в ней два адреса или больше, иначе отдельный адрес `/32`
- Форматы сохранения:
  - только IP-адреса
  - Windows route (`route add`)
  - Linux route (`ip route`)
  - Keenetic BAT (`route add` для bat-файлов)
  - Keenetic CLI (`ip route` с интерфейсом)
  - CIDR-нотация
  - Mikrotik firewall (`/ip/firewall/address-list`)
  - OpenVPN (`push "route"`)
  - WireGuard (одной строкой через запятую)
  - AmneziaVPN (JSON для раздельного туннелирования, сохраняется в `ip.json`)
- Для формата Keenetic BAT список длиннее 999 строк делится на файлы `ip_p1.txt`, `ip_p2.txt` и т.д., исходный `ip.txt` при этом удаляется.
- В формате Keenetic CLI комментарий маршрута — `!Service`. В формате Mikrotik комментарий не добавляется.

### Использование

#### Linux/macOS

1. Установите зависимости (см. выше).

2. Создайте файл `ip.txt` в корневой папке репозитория и добавьте в него IP-адреса (по одному на строку) или любой текст, содержащий IP-адреса.

   Пример содержимого `ip.txt`:
   ```
   192.168.1.1
   10.0.0.1
   Какой-то текст с IP: 172.16.0.1
   ```

3. Запустите утилиту из корневой папки репозитория:

   ```bash
   python -m utilities.convert
   ```

4. Ответьте на вопросы:
   - исключить ли IP-адреса Cloudflare (`1` — да, `Enter` — нет);
   - агрегация (`1` — /16, `2` — /24, `3` — mix, `Enter` — без агрегации);
   - формат сохранения (`1`–`9` или `Enter` для простого списка IP);
   - шлюз, интерфейс или имя списка, если выбранный формат их требует.

5. Результат будет записан в `ip.txt` (или в несколько файлов для формата Keenetic BAT).

#### Windows

См. [инструкцию для Windows](https://github.com/Ground-Zerro/DomainMapper/tree/main/utilities/win#convert): `convert.bat` сам установит Python и зависимости.

## extract_apex_domains

Извлекает домены первого уровня (apex-домены) из списков сервисов. Обрабатывает все txt-файлы в папке `platforms` и сохраняет уникальные apex-домены в отдельную папку. Может быть полезно для настройки DNS-маршрутизации в расширениях и конфигураторах.

### Функции

- Извлекает основной домен из поддоменов (например, из `subdomain.example.com` получает `example.com`).
- Поддерживает распространённые двухуровневые TLD (например, `co.uk`, `com.au`).
- Пропускает пустые строки и строки, начинающиеся с `#`.
- Удаляет дубликаты и сортирует результат.
- Сохраняет результаты в папку `platforms_apex` с теми же именами файлов.

### Использование

#### Linux/macOS

```bash
python utilities/extract_apex_domains.py
```

Сторонние библиотеки не нужны. Результаты будут сохранены в папке `platforms_apex`.

#### Windows

Запустите `utilities\win\extract_apex_domains.bat`. Результаты будут сохранены в папке `platforms_apex`.

### Пример

**Входной файл** (`platforms/dns-youtube.txt`):
```
r1.sn-0hvcpax-30a6.googlevideo.com
manifest.googlevideo.com
i.ytimg.com
googleapis.com
```

**Выходной файл** (`platforms_apex/dns-youtube.txt`):
```
googleapis.com
googlevideo.com
ytimg.com
```

## subdomain

Собирает субдомены (A-записи) указанного домена с сайта [rapiddns.io](https://rapiddns.io/subdomain/).

### Функции

- Последовательно загружает страницы результатов и извлекает домены из строк таблицы с типом записи `A`.
- Делает паузу 2–5 секунд между страницами.
- Повторяет запрос до 5 раз при ответе HTTP 429 (слишком много запросов).
- Останавливается, если три раза подряд получена пустая страница или если данные на трёх последних страницах одинаковы.

### Использование

1. Установите зависимости (см. выше).

2. Запустите скрипт:

   ```bash
   python utilities/subdomain.py
   ```

3. Введите домен, субдомены которого нужно найти, например:

   ```
   example.com
   ```

4. Найденные субдомены будут сохранены в файл `result.txt` в текущей папке.

## verified

Проверяет, делегированы ли домены (отвечают ли они на DNS-запросы).

### Функции

- Проверяет каждый домен через Google Public DNS, Cloudflare DNS и Yandex DNS. Домен считается делегированным, если хотя бы один из серверов вернул A-запись.
- Одновременно проверяется не более 40 доменов.
- Выводит статус каждого домена: делегирован, припаркован/неактивен или ошибка.
- Домены, не подтверждённые как делегированные, проверяются повторно.
- Пустые строки и повторы во входном файле пропускаются.

### Использование

1. Установите зависимости (см. выше).

2. Поместите файл `result.txt` со списком доменов (по одному на строку) в текущую папку. Например, результат работы `subdomain`.

3. Запустите скрипт:

   ```bash
   python utilities/verified.py
   ```

4. Активные домены будут сохранены в файл `verified_domains.txt`.
